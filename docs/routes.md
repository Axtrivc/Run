# 路线页 + 实务页

## 按收入来源分流（决策指南摘要）

- 目的国雇主 offer → 技术工作 / 欧盟蓝卡：德国、荷兰、爱尔兰、法国等
- 境外雇主 / 客户 → 数字游民签证：西班牙、葡萄牙、希腊、克罗地亚等
- 自己当老板 → 创业 / 自雇：爱尔兰 STEP、芬兰、荷兰等
- 一笔长期闲置资金 → 投资居留：希腊、塞浦路斯、马耳他、匈牙利等
