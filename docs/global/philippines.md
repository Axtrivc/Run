## SRRV 特别退休居留签证

在菲律宾指定银行存一笔定期存款即可获得可无限期居留的退休签证，2025 年起 40 岁就能申请。

| 项目 | 内容 |
| --- | --- |
| 年龄 | ≥40 岁（2025-09 起，原为 50 岁） |
| 50 岁以上存款 | 有养老金 USD 15,000 / 无养老金 USD 30,000 |
| 40–49 岁存款 | 有养老金 USD 25,000 / 无养老金 USD 50,000 |
| 养老金标准 | 单人终身养老金 ≥ USD 800/月 |
| 存款性质 | 本人名下定期存款，不是费用 |
| 类别 | 仅剩 Classic 和 Courtesy |

适合：想在东南亚养老、预算有限的人; 有稳定养老金的退休人士

不适合：需要在菲律宾工作（需另办工作许可）

流程：
- 向菲律宾退休局（PRA）咨询并准备材料：
- 在 PRA 认可银行开定期存款：
- 递交申请、体检、无犯罪证明：
- 获批领卡：
- 每年向 PRA 年报：

提示：网上很多页面仍写'50 岁、USD 20,000'的旧规则; 以 PRA 官网公布的金额为准

## SIRV 特别投资者居留签证

投资 7.5 万美元于菲律宾合格企业或证券，获得可无限期居留的投资者签证。

| 项目 | 内容 |
| --- | --- |
| 投资额 | ≥ USD 75,000 |
| 年龄 | 21 岁起 |
| 流程 | 先 6 个月试用签证，资金先存入 DBP 或 Land Bank 比索定存，再转为合格投资 |
| 不可投资 | 公寓、批发贸易、零售（含餐馆） |
| 维持 | 每年向投资署（BOI）年报，投资不得低于 7.5 万美元 |

适合：想在菲律宾长期居住的投资者

不适合：想买公寓拿签证

流程：
- 汇入 7.5 万美元至指定银行：
- 申请 6 个月试用签证：
- 180 天内转为合格投资并报 BOI：
- 获正式 SIRV：
- 每年年报：

提示：不报年报或投资低于门槛会被自动取消签证
