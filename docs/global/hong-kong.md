## 高端人才通行证（高才通）

高收入或名校毕业即可申请，无需工作 offer。

| 项目 | 内容 |
| --- | --- |
| A 类 | 上年收入 ≥ HKD 250 万，首签 3 年 |
| B 类 | 指定大学本科 + 近 5 年 3 年经验，2 年 |
| C 类 | 指定大学近 5 年毕业，每年 1 万名额 |
| 费用 | HKD 600 + 1,300/人 |
| 续签 | 需有工作或业务 |

适合：名校毕业的内地人才

不适合：续签时没有在港工作

流程：
- 线上递交：
- 约 4 周审批：
- 入境领证：
- 在港工作/创业：
- 续签：
- 满 7 年申请永居：

提示：2026 起续签核查社保和税表
