## F-1 留学 → OPT → H-1B

最常见的路径：读书 → 实习工作 → 抽签拿工作签证 → 雇主办绿卡。

| 项目 | 内容 |
| --- | --- |
| OPT | 毕业后 1 年，STEM 专业共 3 年 |
| H-1B 抽签 | 2026-02 起按工资等级加权（Level IV 4 次机会） |
| FY2027 名额 | 已满 |
| 10 万美元附加费 | 2026-09-30 被法院禁止执行，政府上诉中 |
| 期限 | 3 年 + 3 年 |

适合：在美读 STEM 硕博; 能拿到较高工资等级 offer

不适合：工资处于 Level I; 人在境外首次申请（附加费风险）

流程：
- F-1 读书：
- OPT 工作：STEM 可延至 3 年
- 雇主注册 H-1B 抽签：每年 3 月
- 中签后递交 I-129：
- 雇主办 PERM + I-140：转绿卡

提示：F-1 境内转 H-1B 不适用 10 万美元附加费

## EB-1A 杰出人才 / EB-2 NIW 国家利益豁免

不需要雇主，自己申请绿卡；科研人员和高成就专业人士的主要途径。

| 项目 | 内容 |
| --- | --- |
| EB-1A 中国排期 | FAD 2023-08-01（2026-11） |
| EB-2 中国排期 | FAD 2021-10-01；递交日期 2023-01-01 |
| 雇主 | 不需要 |
| 证明 | EB-1A 领域顶尖；NIW 对美国有国家利益 |

适合：论文、专利、奖项、媒体报道丰富的人

不适合：指望很快拿绿卡的中国出生申请人

流程：
- 整理成就证据：论文引用、推荐信、奖项
- 递交 I-140：可加急
- 等待排期：看 Visa Bulletin
- I-485 或领馆办理：

提示：NIW 不能降级到 EB-3（需 PERM）; '金卡'本质也是 EB-1/NIW，同样受中国排期约束

## EB-5 投资移民

投资 80 万美元（TEA 区域）直接申请绿卡，乡村预留名额可绕开中国排期。

| 项目 | 内容 |
| --- | --- |
| TEA 区域 | USD 800,000 |
| 非 TEA | USD 1,050,000 |
| 额外费用 | 区域中心费约 USD 80,000 + 律师费 2.5–3.5 万 |
| 2027-01-01 | 按通胀上调（预计 TEA 约 90 万以上） |
| 结果 | 条件绿卡 → 正式绿卡 |

适合：资金充足、来源清晰

不适合：资金无法合规出境

流程：
- 选项目（区域中心）：尽调
- 资金出境并投资：
- 递交 I-526E：
- 条件绿卡：
- 2 年后 I-829 去条件：

提示：递交日锁定投资额，2026 年底前递交仍按 80 万
