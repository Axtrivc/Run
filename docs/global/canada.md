## Express Entry 快速通道

CRS 打分池，按类别定期抽签，获邀后约 6 个月拿永居；2026-11-03 起加拿大工作经验和高薪职业 offer 可加更多分，offer 不再需要 LMIA。

| 项目 | 内容 |
| --- | --- |
| 2026-11-03 新规 | 加拿大工作经验或高薪职业 offer（如工程师、电工）加分更多 |
| 工作 offer | 不再需要 LMIA，由 IRCC 直接审核真实性 |
| 已在池中 | 分数自动重算，重算期间抽签暂停 |
| CEC 分数线 | 2026 年约 507–523 |
| 法语类 | 382–420 |
| 医疗类 | 467–475 |
| 省提名加分 | +600 |
| 2026 至 10 月 | 已发 13.5 万份邀请 |

适合：有加拿大工作经验; 法语好; 医疗、技工等定向职业

不适合：年龄大、无加拿大经验、无法语

流程：
- 语言考试 + 学历认证（ECA）：
- 建立 EE 档案：
- 等待抽签（ITA）：
- 60 天内递交永居：
- 登陆：

提示：法语仍是最有效的加分项之一; IRCC 正考虑把 CEC、FSW、FST 合并为一个项目（尚未确定）
