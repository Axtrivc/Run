## Employment Pass

主流专业人士工作准证，薪资随年龄递增并需通过 COMPASS 积分。

| 项目 | 内容 |
| --- | --- |
| 最低月薪 | SGD 5,600（金融 6,200），45 岁以上 10,700 |
| COMPASS | ≥40 分；月薪 ≥ 22,500 豁免 |
| 招聘 | 雇主先发布 14 天 |
| 2027 起 | SGD 6,000（金融 6,600） |
