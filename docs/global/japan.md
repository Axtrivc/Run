## 高度专门职（高度人才）

按学历、年收入、年龄、日语打分，70 分 3 年、80 分 1 年可申请永住。

| 项目 | 内容 |
| --- | --- |
| 70 分 | 3 年申请永住 |
| 80 分 | 1 年申请永住 |
| J-Skip | 高收入/高学历直接认定 |
| 审查重点 | 纳税、年金、健康保险 |

适合：硕博学历、年收入较高的技术人员

不适合：社保年金缴纳不全

流程：
- 计算分数：入管厅积分表
- 以技人国或高度人才身份工作：
- 保持分数满 1/3 年：
- 申请永住：

提示：2026-10-01 起永住要求和手续费有调整
