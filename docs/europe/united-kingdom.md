### 英国技术工作签证（Skilled Worker）（RUN 补充）

英国最主流的工作移民路线：持牌雇主担保、学士级岗位、年薪 41,700 英镑起。

| 项目 | 内容 |
| --- | --- |
| 薪资 | ≥ GBP 41,700/年或职业标准工资（取高者），时薪 ≥ GBP 17.13 |
| 岗位 | RQF 6（学士级）以上；中等技能岗位需在紧缺清单 |
| 英语 | B2（2026-01-08 起） |
| 雇主 | 持牌担保雇主 |
| 永居（新规） | 标准 10 年；近 5 年有 3 年年薪 ≥ £50,271 为 5 年；≥ £125,141 为 3 年 |

适合：拿到英国 offer 的本科以上专业人士
不适合：中低技能岗位

流程：
- 雇主出具担保证明（CoS）：
- 线上申请 + 生物信息：
- 缴移民医疗附加费（IHS）：
- 入境领 eVisa：

材料：CoS 担保证明; 英语 B2 证明; 护照; 肺结核检测（中国申请人需要）

来源：

### 英国高潜力人才签证（HPI）（RUN 补充）

全球前约 100 名大学近 5 年毕业生可直接申请 2 年开放工作签证，无需 offer。

| 项目 | 内容 |
| --- | --- |
| 学历 | 名单内大学近 5 年毕业 |
| 期限 | 2 年（博士 3 年），不可续 |
| 名额 | 每年 8,000（2025-11 起） |
| 英语 | B2 |
| 永居 | ❌ 新规下 HPI 时间不计入永居年限 |

适合：北大、清华等名单内大学的毕业生（以 GOV.UK 当年名单为准）
不适合：想直接拿永居
