### 希腊财务独立人士居留（FIP）（RUN 补充）

境外被动收入每月 3,500 欧，即可在希腊住 3 年可续；不能在希腊工作。

| 项目 | 内容 |
| --- | --- |
| 收入 | 境外被动收入 ≥ EUR 3,500/月（2024-09 起） |
| 家属 | 配偶 +20%，每个孩子 +15% |
| 或存款 | 单人约 EUR 126,000；夫妻 151,200 |
| 期限 | 3 年，可同期续签 |
| 续签 | 每年在希腊住满 6 个月 |
| 工作 | ❌ 不允许 |

适合：退休或有高额被动收入的家庭
不适合：需要工作收入

流程：
- 领馆 D 签证：
- 入境后申请居留（I.8 类）：
- 生物信息：
- 续签：3 年后

材料：被动收入证明; 希腊住房证明; 医疗保险; 无犯罪证明
