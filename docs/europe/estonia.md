### 爱沙尼亚创业签证（Startup Visa）（RUN 补充）

创业委员会 10 个工作日内评审，不收费、无最低注资，通过后可拿 D 签证或 2+3 年居留。

| 项目 | 内容 |
| --- | --- |
| 评审 | 创业委员会，10 个工作日，免费 |
| 注资 | 无最低要求（普通商业投资居留需 6.5 万欧） |
| 个人资金 | 约 EUR 800/月 |
| 签证 | D 签证 EUR 120 |
| 居留 | 2+3 年，境内 EUR 350 / 境外 380 |
| 招人 | 免移民配额和最低工资要求 |

适合：有可扩展科技项目的创始人
不适合：普通生意、无创新性

流程：
- 向 Startup Estonia 提交：
- 委员会认定（Startup Code）：
- 申请 D 签证或居留：
- 注册公司：可用 e-Residency 远程办理

材料：商业计划; 团队与产品材料; 资金证明; 医保 ≥ EUR 30,000

来源：
- [e-Residency: Startup Visa vs e-Residency](https://www.e-resident.gov.ee/blog/posts/estonian-startup-visa-vs-e-residency/)
- [Remote Work Europe: Estonia Startup Visa](https://remoteworkeurope.eu/insights/estonia-startup-visa-explained/)
