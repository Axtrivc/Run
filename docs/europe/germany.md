### 德国机会卡（Chancenkarte）（RUN 补充）

没有 offer 也能先去德国找工作：积分 ≥6 分，最长 1 年，期间可兼职每周 20 小时。

| 项目 | 内容 |
| --- | --- |
| 积分 | ≥6 分（学历认可程度、经验、德语/英语、年龄、与德国联系） |
| 基本条件 | 学位或 ≥2 年职业培训 + 德语 A1 或英语 B2 |
| 资金 | 冻结账户 EUR 1,091/月 × 12 = EUR 13,092 |
| 期限 | 最长 12 个月，不可延期 |
| 工作 | 每周 ≤20 小时兼职 + 不限次数 2 周试工 |
| 费用 | 约 EUR 75 |

适合：没有 offer、想先到德国找工作的本科及以上学历者; 会一点德语的人（加分多）
不适合：资金不足 1.3 万欧; 学历未被认可且无职业培训

流程：
- 自测积分：Make it in Germany 积分计算器
- 学历认证：anabin / ZAB
- 开冻结账户：存入 EUR 13,092
- 使馆递交国家签证：
- 入境找工作：找到后转技术工人签证或蓝卡

材料：学历证明及认可情况; 语言证书; 冻结账户证明; 简历、工作证明; 医疗保险

来源：
- [Make it in Germany: Opportunity Card](https://www.make-it-in-germany.com/en/visa-residence/types/job-search-opportunity-card)
- [livingineurope.net: Opportunity Card 2026](https://livingineurope.net/visas/germany-opportunity-card)

### 德国技术工人签证（§18a / §18b）（RUN 补充）

有德国 offer 但达不到蓝卡薪资时的主要选择；45 岁以下没有固定薪资门槛，3 年可永居。

| 项目 | 内容 |
| --- | --- |
| §18a | 职业培训（≥2 年，需在德认可） |
| §18b | 大学学历（anabin 可比），2024 起岗位不必与专业对口 |
| 薪资 | 45 岁以下无固定门槛；45 岁及以上首次 EUR 55,770/年或有养老保障 |
| 就业局 | 需联邦就业局批准 |
| 有效期 | 最长 4 年 |
| 永居 | 3 年（§18c） |

适合：薪资低于蓝卡门槛的技术人员; 有职业培训（非本科）的技工
不适合：学历/培训未获认可且不走认可伙伴路线

流程：
- 学历/培训认证：ZAB 或 IHK FOSA
- 德国 offer：
- 使馆国家签证 + 就业局批准：
- 入境领居留：
- 3 年后永居：

材料：劳动合同; 学历/培训认可证明; 护照; 医保

来源：
- [Tieben Law: §§18a/18b requirements](https://www.mth-partner.de/en/residence-permit-for-skilled-workers-after-18a-residence-permit-for-skilled-workers-with-vocational-training-and-18b-residence-permit-for-skilled-workers-with-academic-training/)
