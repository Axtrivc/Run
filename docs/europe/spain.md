### 西班牙非营利居留（No Lucrativa / NLV）（RUN 补充）

靠被动收入或存款在西班牙生活、不工作的居留；门槛比数字游民签证低，但不能做任何工作（含远程）。

| 项目 | 内容 |
| --- | --- |
| 主申请人 | IPREM 400% = EUR 2,400/月（EUR 28,800/年） |
| 每位家属 | +EUR 600/月（IPREM 100%） |
| 夫妻 | EUR 3,000/月；夫妻+1 孩 3,600；+2 孩 4,200 |
| 工作 | ❌ 不允许（含远程工作） |
| 首次 | 1 年 |
| 续签 | 每次 2 年，需每年在西班牙住 >183 天 |
| 保险 | 无免赔额的私人医保 |

适合：有租金、股息、养老金等被动收入或足额存款; 退休或半退休人士
不适合：需要继续上班（含远程）——应走数字游民签证

流程：
- 准备资金证明：被动收入或存款，按家庭人数计算
- 买私人医保：西班牙保险公司、无免赔额
- 领馆递交：附无犯罪证明、体检证明
- 入境后 1 个月内办 TIE：
- 续签：第 1 年后续 2 年

材料：护照、申请表 EX-01; 资金或被动收入证明; 私人医疗保险; 无犯罪证明（认证 + 翻译）; 医疗证明; 790-052 缴费凭证
