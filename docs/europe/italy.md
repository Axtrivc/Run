### 意大利选择性居留（Elective Residence）（RUN 补充）

靠被动收入在意大利生活的居留，官方最低约 3.1 万欧/年，但各领馆常要求更高。

| 项目 | 内容 |
| --- | --- |
| 最低收入 | 约 EUR 31,160/年被动收入 |
| 家属 | 配偶 +20%，每个子女 +5% |
| 实际 | 不少领馆期望单人 4–6 万欧 |
| 工作 | ❌ 不允许（含远程） |
| 住房 | 须有 ≥12 个月登记租约或产权 |
| 期限 | 1 年可续；5 年永居，10 年入籍 |

适合：有养老金、租金、股息收入的人
不适合：想远程工作的人
